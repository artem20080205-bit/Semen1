# Лабораторная работа 1

## О проекте
Консольная программа для управления списком дел (To-Do List). 
Написана на C++ в рамках учебного семинара по ООП.


## Что умеет программа

**Класс Task (Задача)**
- Хранит: номер задачи, описание, статус (выполнено/нет), приоритет
- Меняет статус на "выполнено"
- Меняет описание
- Выводит информацию о задаче
- Сортируется по приоритету

**Класс TaskManager (Управление задачами)**
- Добавляет новые задачи
- Удаляет задачи по номеру
- Отмечает задачи выполненными
- Ищет задачи по номеру
- Показывает все задачи
- Показывает только выполненные
- Показывает только невыполненные
- Показывает задачи с высоким приоритетом
- Сортирует задачи (по приоритету, по номеру)
- Удаляет все выполненные задачи
- Показывает статистику
